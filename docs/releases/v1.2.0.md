# v1.2.0 — Group 14 community baseline

Initial community release of **AI-Based Virtual Laboratory for Battery Digital Twin (SOC/SOH)**,
by Bharathwaj Manoharan, Gokul Vasan R, and Arvind Kumar.

## Included

- Python battery engine and Streamlit interface.
- Cell and vehicle data processing, calibration, estimation, and validation code.
- Original reports, presentation, diagrams, screenshots, and small sample datasets.
- Contributor guide, development roadmap, and MIT licence for original code and documentation.

## Download both parts

1. Clone the repository at tag `v1.2.0`, or download the release's automatic source ZIP.
2. Download `EVT_LLT_Project-v1.2.0-data.zip` and `SHA256SUMS` from this release.
3. Verify the checksum and extract the data ZIP into the source folder beside `app.py`.
4. Follow the README to install dependencies and start the lab.

The data asset supplies both raw archives, 11 processed parquet tables, three trained
reference-model files, and 10 files in `models/model_metrics/`. The automatic source download does not
contain these ignored assets. Third-party dataset and font terms are preserved separately
from the MIT licence.

The engine and interface are preserved from the Group 14 baseline. Refer to the README
and original report for results and model limitations. Application tests were not rerun
for this packaging release; the existing tests are available for contributors to run.

See [data setup](https://github.com/SreevanjiManoharan179/EVT_LLT_Project/blob/v1.2.0/docs/DATA_SETUP.md)
and [contribution guidance](https://github.com/SreevanjiManoharan179/EVT_LLT_Project/blob/v1.2.0/CONTRIBUTING.md).
